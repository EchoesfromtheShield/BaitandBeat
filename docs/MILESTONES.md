# Reduced Milestones

## M0 - Standalone Vertical Slice

Goal: make the full fishing loop playable on Norns only.

Required:

- `CAST`, `EXPLORE`, `RESONANCE`, `STRUGGLE`, `SURFACE`;
- local controls using Norns keys and encoders;
- fish resonance while exploring;
- bite when depth and hook overlap line up;
- tension, slack, overload, capture progress;
- one captured loop for each role: crab, fish, octopus.

Exit gate: the loop is playable with only Norns controls.

## M1 - Musical Feel Pass

Goal: make each fish role musically distinct and useful in combination.

Required:

- crab produces varied kick, snare, and rim phrases;
- fish produces clocked arpeggiator phrases;
- octopus produces slow harmonic arcs;
- captured loops can be mixed, modulated, freed, and replaced;
- BPM, root note, and scale can be adjusted from page 3.

Exit gate: record a short session and decide whether the musical loop is worth
developing further.

## M2 - Polish

Goal: make the public Norns script feel coherent.

Required:

- clean script metadata and instructions;
- stable launch behavior;
- readable pixel main page;
- clear struggle page and loop edit pages;
- no external hardware requirement.
